# 😎 My Portfolio

A personal portfolio website with an interactive terminal-style UI built by **Mohammad Adnan**, Frontend Engineer based in Noida, India.

🔗 **Live:** https://my-portfolio-nu-swart-61.vercel.app

---

## Tech Stack

- **React 18** — UI framework
- **Tailwind CSS** — Utility-first styling
- **SCSS** — Custom animations & styles
- **React Router DOM** — Client-side routing
- **EmailJS** — Contact form integration
- **React Hot Toast** — Notifications
- **React Icons** — Icon library

## Features

- Terminal-style interactive prompt with commands (`about`, `skills`, `experience`, `projects`, `contact`, `resume`)
- Sections: About, Skills, Experience, Education, Portfolio, Testimonials, Contact
- Downloadable resume
- Animated background & top light effects
- Fully responsive design

## Getting Started

```bash
npm install
npm start
```

## Available Terminal Commands

| Command     | Description                        |
|-------------|------------------------------------|
| `about`     | Learn about me                     |
| `skills`    | View my tech skills                |
| `experience`| View work experience               |
| `projects`  | View my projects                   |
| `contact`   | Get contact details                |
| `resume`    | View / download resume             |
| `help`      | List all commands                  |
| `clear`     | Clear the terminal                 |
| `theme`     | Customize theme                    |
| `setname`   | Replace default 'root' with your name |
